# AI image prompts

Images to generate with another AI image tool. Until a file exists at its path, the page shows a dashed
placeholder with the prompt (components/premium/ai-image.tsx). Drop the generated file at the path and
the page picks it up; nothing else needs changing.

Shared style for every image: photorealistic editorial photo, 4:5 portrait (for example 1600×2000),
Indian people and settings, soft natural light, warm neutral palette with navy (#0c3474) and sky-blue
(#2c9cfa) accents, shallow depth of field, calm and premium. No logos, no readable screen text, no watermarks.
Leave empty space where the overlay card sits (noted per image). Export as JPG, under 400 KB.
